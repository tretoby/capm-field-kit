# CAPM Field Kit

A free study tool for the PMI CAPM® exam. Instead of just reading definitions, you see every major project document filled out for one realistic project, and you get hands-on simulators that show how the concepts work.

**👉 Open the kit: https://tretoby.github.io/capm-field-kit/Index.html**

It works on any phone or computer. No sign-up, no download.

## What's inside

Every example comes from one fictional project: deploying 24 GPU racks in a datacenter. Each page starts with a plain-English explanation, a real-world comparison, and the key terms defined.

**Example documents**
- Business case, project charter, stakeholder register
- Scope statement, work breakdown structure (WBS), RACI chart, communications plan
- Risk register, issue log, change request and change log, lessons learned
- Product backlog with user stories, sprint board, Definition of Done
- Requirements traceability matrix

**Simulators**
- **Critical path:** change task durations and watch the critical path and float update
- **Earned value:** slide through the project and see CPI, SPI, EAC and more
- **Risk heat map:** score risks by probability and impact
- **Burndown charts:** read five common sprint patterns
- **Kanban:** see how WIP limits speed up work
- **Estimating and communication channels:** quick calculators for exam formulas
- **Exam scenarios:** "what should the PM do?" questions with explanations for every answer

## How to study with it

1. Open a topic and read the plain-English explanation first.
2. Study the filled-in example and the key terms.
3. Try the simulator if there is one, then the exam scenarios.
